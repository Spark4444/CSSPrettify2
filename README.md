# CSSPrettify2

A desktop application for optimizing and formatting CSS files with a clean, intuitive user interface.

CSSPrettify2 is the next generation of the original CSSPrettify tool, rebuilt using Electron for cross-platform compatibility and improved performance. It replaces the previous Python Tkinter-based GUI with a modern web-based interface.

## Features

- **Sort Selectors**: Organize CSS selectors alphabetically for better readability
- **Sort Properties**: Arrange CSS properties in alphabetical order
- **Merge Duplicates**: Combine duplicate CSS rules to reduce file size
- **Merge Repeated Selectors**: Consolidate selectors that appear multiple times
- **Drag & Drop Support**: Simply drag CSS files into the application

## Performance

With all optimization options enabled, CSSPrettify2 achieves approximately **30% file size reduction** on typical hand-written CSS files.

## Installation

You can use either the Windows executable or the executable for Mac.
